    # 数据结构 - 排序算法笔记

## 一、基本概念

### 1.1 排序算法分类
- **比较类排序**：通过比较元素大小决定相对次序
  - 时间复杂度下限：O(n log n)
  - 包括：冒泡、选择、插入、希尔、快速、归并、堆排序
- **非比较类排序**：不通过比较，利用数据本身特性
  - 时间复杂度可突破O(n log n)
  - 包括：计数、桶、基数排序

### 1.2 重要术语
- **稳定性**：相等元素排序后相对位置是否保持不变
  - 稳定：A在B前且A=B → 排序后A仍在B前
  - 不稳定：可能改变相等元素的相对顺序
- **时间复杂度**：算法执行所需时间的理论度量
- **空间复杂度**：算法执行所需额外内存空间
- **原地排序**：仅使用常数级额外空间（O(1)）
- **内部排序**：所有操作在内存中完成
- **外部排序**：数据量过大需借助外部存储

## 二、经典排序算法详解

### 2.1 冒泡排序 (Bubble Sort)
- **原理**：重复遍历待排序序列，比较相邻元素并交换
- **时间复杂度**：
  - 最好：O(n) - 已有序，一次遍历即可
  - 平均：O(n²)
  - 最坏：O(n²) - 完全逆序
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：✅ 稳定
- **特点**：简单易懂，但效率低，适合小规模数据

### 2.2 选择排序 (Selection Sort)
- **原理**：每次从未排序部分选择最小（大）元素放到已排序末尾
- **时间复杂度**：O(n²) - 无论最好、平均、最坏情况
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：❌ 不稳定
- **特点**：交换次数最少（最多n-1次），但比较次数多

### 2.3 插入排序 (Insertion Sort)
- **原理**：构建有序序列，对未排序元素在已排序序列中从后向前扫描插入
- **时间复杂度**：
  - 最好：O(n) - 已有序
  - 平均：O(n²)
  - 最坏：O(n²) - 完全逆序
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：✅ 稳定
- **特点**：对小规模或基本有序数据效率高，是希尔排序的基础

### 2.4 希尔排序 (Shell Sort)
- **原理**：插入排序的改进版，按一定间隔分组进行插入排序，逐步缩小间隔
- **时间复杂度**：依赖间隔序列，通常为O(n^1.3)~O(n²)
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：❌ 不稳定
- **特点**：第一个突破O(n²)的排序算法，适合中等规模数据

### 2.5 快速排序 (Quick Sort)
- **原理**：分治法，选择基准元素(pivot)，将数组分为小于和大于基准的两部分，递归排序
- **时间复杂度**：
  - 最好/平均：O(n log n)
  - 最坏：O(n²) - 每次选到极值作为基准
- **空间复杂度**：O(log n) - 递归调用栈深度
- **稳定性**：❌ 不稳定
- **特点**：实际应用中最快的通用排序算法之一，原地排序

### 2.6 归并排序 (Merge Sort)
- **原理**：分治法，将数组递归分割成单元素，再两两合并有序数组
- **时间复杂度**：O(n log n) - 所有情况都相同
- **空间复杂度**：O(n) - 需要额外空间存储合并结果
- **稳定性**：✅ 稳定
- **特点**：稳定且时间复杂度稳定，适合大数据量和链表排序

### 2.7 堆排序 (Heap Sort)
- **原理**：利用堆数据结构（完全二叉树），构建大顶堆/小顶堆，逐个取出堆顶元素
- **时间复杂度**：O(n log n) - 所有情况都相同
- **空间复杂度**：O(1) - 原地排序
- **稳定性**：❌ 不稳定
- **特点**：时间复杂度稳定，原地排序，但不稳定

### 2.8 计数排序 (Counting Sort)
- **原理**：统计每个元素出现次数，按统计结果重构数组
- **时间复杂度**：O(n + k) - k为数据范围
- **空间复杂度**：O(n + k)
- **稳定性**：✅ 稳定
- **特点**：适用于数据范围k不太大的整数排序，线性时间复杂度

### 2.9 桶排序 (Bucket Sort)
- **原理**：将数据分到有限数量的桶中，每个桶内单独排序，再按序合并
- **时间复杂度**：O(n + k) - 平均情况，k为桶数
- **空间复杂度**：O(n + k)
- **稳定性**：✅ 稳定（若桶内排序稳定）
- **特点**：适合均匀分布的数据，可视为计数排序的泛化

### 2.10 基数排序 (Radix Sort)
- **原理**：按数字位数（个、十、百...）或字符位进行多次计数排序
- **时间复杂度**：O(d × (n + r)) - d为位数，r为基数
- **空间复杂度**：O(n + r)
- **特点**：适用于整数或字符串排序，线性时间复杂度

## 四、选择指南

- **小规模数据（n < 50）**：插入排序（实现简单，常数因子小）
- **大规模通用排序**：快速排序（平均性能最优）、归并排序（需要稳定排序时）
- **内存受限**：堆排序、快速排序（原地排序）
- **需要稳定排序**：归并排序、插入排序、冒泡排序
- **整数且范围不大**：计数排序、基数排序
- **链表排序**：归并排序（无需随机访问）
